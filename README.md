## 📝 О проекте
Данный проект представляет собой полноценную 3D-реализацию классической игры «Морской бой». Вместо скучной консольной версии игра предлагает погружение в атмосферу морского сражения с видом сверху, параболическими траекториями снарядов, взрывами и тряской камеры.

Главная особенность проекта — **чистая архитектура**. Логика игры (правила, поле, ИИ) полностью отделена от движка Unity и написана на классическом C# без использования `MonoBehaviour`. Это позволяет легко тестировать ядро игры и обеспечивает высокую производительность.

## ✨ Ключевые особенности

### 🎮 Геймплей
* **Ручная расстановка:** Игрок сам размещает корабли на поле, видит цветовой предпросмотр (зеленый/красный) и может вращать корабли нажатием клавиши `R`.
* **Спецспособности:** Помимо обычных выстрелов, у игрока и ИИ есть по одной «Бомбардировке» (урон по площади 3x3) и «Торпеде» (линейный урон 1x3).
* **Правило повторного хода:** При попадании игрок (или ИИ) получает право на дополнительный выстрел.

### 🧠 Продвинутый ИИ
Искусственный интеллект не просто стреляет случайным образом. Алгоритм включает в себя:
1. **Шахматный порядок:** Для поиска кораблей ИИ обстреливает клетки в шахматном порядке (через одну). Это математически оптимизированный способ найти самые маленькие (однопалубные) корабли за минимальное число ходов.
2. **Анализ направления:** При попадании ИИ определяет, как стоит корабль (горизонтально или вертикально), и ведет огонь строго вдоль линии, отсекая лишние варианты.
3. **Умные способности:** ИИ не тратит бомбы впустую. Он использует их для гарантированного уничтожения раненого корабля или (в редких случаях) для разведки, если долго не может найти цель.

### 🎨 Визуал и UX
* **URP (Universal Render Pipeline):** Настроено освещение, прозрачные клетки и стилизованная вода.
* **Анимации:** Снаряды летят по параболе (математически рассчитанной дуге).
* **Спецэффекты:** Тряска камеры (Camera Shake) при взрывах, реализованная через корутины. При попадании 3D-модель палубы меняет цвет.
* **UI:** Полноценное меню, HUD с кнопками способностей и экран победы/поражения.

### Слой Core (Игровое ядро)

* Не зависит от Unity (`using UnityEngine` отсутствует).
* Использует структуры (`readonly struct Coord`), чтобы избежать лишней нагрузки на сборщик мусора (GC).
* Содержит всю математику проверки правил расстановки, попаданий и потоплений.
* ИИ (`SimpleAi.cs`) написан здесь же, что позволяет легко менять его сложность.

### Слой Game (Презентация)

* Использует паттерн MVC (Model-View-Controller) в упрощенном виде.
* `GameManager` управляет состояниями (ход игрока, ход ИИ, конец игры).
* `BoardView` отвечает за отрисовку 3D-сетки (с использованием `MaterialPropertyBlock` для оптимизации покраски клеток).
* `Projectile` и `Explosion` — легковесные скрипты для визуализации.

## 🚀 Как запустить

### Вариант 1: Скачать готовую сборку (Рекомендуется)

* Перейдите в раздел **Releases** на этой странице.
* Скачайте архив под вашу ОС (Windows или Linux).
* Распакуйте архив и запустите исполняемый файл (`.exe` или `SeaBattle.x86_64`).

### Вариант 2: Запуск из исходников

* Установите Unity 6 (6000.0.37f1) или более новую версию.
* Клонируйте репозиторий:

```bash
git clone https://github.com/ВАШ_НИК/SeaBattle3D.git ```

* Откройте папку проекта через Unity Hub.
* Откройте сцену Assets/Scenes/MainScene.unity и нажмите Play.

        ├── PlacementManager.cs
